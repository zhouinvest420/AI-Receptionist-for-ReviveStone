# AI-Receptionist-for-ReviveStone
Case Study: An AI voice receptionist that answers calls, qualifies leads, and books appointments built in GoHighLevel for Revive Stone, a home remodeling business. 

This repo contains the system prompt configuration for **Riley**, the AI voice receptionist built for [Revive Stone Sacramento](https://revivestone.com), a premium stone fabrication and remodeling company serving Greater Northern California.

## What's in here

- **`System-Prompt Template.md`** — the full system prompt that defines Riley's personality, tone, and behavior, including how she handles service questions, books free in-home estimates, manages edge cases (pricing questions, cancellations, irate callers), and stays within brand guardrails (no firm quotes, no competitor talk, etc.)

## About Riley

Riley is a warm, consultative AI voice agent that answers inbound calls for Revive Stone, helping callers with:

- Questions about services (countertops, cabinetry, tile flooring, stone repair)
- Booking free in-home estimates
- Pricing, hours, and showroom info
- Routing complex or sensitive requests to a human team member

Riley runs natively in GoHighLevel (GHL), handling voice, SMS, lead qualification, and appointment booking in one system.

## Usage

The prompt in `System-Prompt Template.md` is designed to be pasted directly into the AI voice agent configuration in GHL. Update the placeholder fields (like business hours, showroom address, or phone number) if those details change.
